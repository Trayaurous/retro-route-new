# 纯前端改造交付记录

日期：2026-10-07。依据 `requirements.md` 开发。本轮未发布网站，未提交或推送仓库。

## 已实现

- 正式入口改成共享响应式 React 应用，移除 Flask API、任务双写和移动演示数据；桌面与移动使用相同的数据模型、编辑逻辑和本地路线库。
- 保留多路线新建、切换、改名、独立复制、删除和单条导出。地点引用统一、允许重复节点，排序只保留仍有效的有向路段。
- 浏览器自动保存、保存时间与失败提示、损坏缓存保护、跨标签页修订冲突、有限撤销／重做。
- UTF-8 JSON 单条导入／导出、整库备份／恢复；先校验和预览，确认后新增或覆盖，不合并，不部分恢复。
- `RR1:` 压缩二维码、图片读取和网页相机扫描。长路线超出单码阈值时改用文件，不截断内容；相机与解码都在本机进行。
- 点击展开交通详情、跨日与超过 24 小时时长、数字键盘时间整理、Explore 分类／链接／长备注、Markdown、预览、主题和独立全屏。
- Apple Maps／Google Maps 显式导航按钮；跳转前尝试保存，保存失败仍保留内存与导出途径。
- 沿用浅色米白、炭黑、橙红，方角粗边框与硬阴影，复用 Lucide 图标与共用表单／弹窗。小入口图标化，必要界面文案使用英文。
- GitHub Pages 工作流仅部署 `dist`；资源采用相对路径，二维码与扫描按需加载。无应用级离线缓存或瓦片批量下载。

## 数据与地图决定

默认统一使用 OpenStreetMap 在线瓦片和 WGS84 坐标；可通过构建环境配置兼容瓦片服务。地图服务可用性、系统地图是否唤起 App，以及实际地点一致性需在目标网络和设备验证。

旧高德坐标按 GCJ-02 近似转换至 WGS84；导入预览允许改选 WGS84。不得把数学往返测试等同于真实导航精度保证。旧副本冲突、失效路段通过迁移说明报告，原始文件不修改。

已只读导出当前数据库到 `migration-exports/legacy-routes-2026-10-07.json`，包含 1 条路线、10 个地点及 4 个路线节点，并验证转换、校验与二维码编码。数据库、旧服务器、原前端备份保留，但没有运行时依赖，私人数据目录已加入忽略规则。

字段、协议、容量与历史上限详见 `data-format.md`。浏览器缓存不是长期备份；不同设备导入后是独立副本，没有自动同步。
